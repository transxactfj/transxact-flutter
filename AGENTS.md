# AGENTS.md

This repo is hand-written — nothing here is generated by Fern (see `docs/adr/0001-client-only-flutter-sdk.md`). `transxact_flutter` is client-only: it never holds a Transxact key and never calls Transxact; every call goes through the Merchant backend. It mirrors `@transxact/react` (`../transxact-react`), so a behaviour change in one usually belongs in the other. Domain vocabulary is in the platform's `CONTEXT.md` (Merchant, Customer, Checkout Session, Test mode / Live mode).

Only edit files inside this repo; changes needed in the platform or other SDKs go on a follow-up list.

Anything matched by `.gitignore` must never be committed or pushed to GitHub — no `git add -f`, no un-ignoring to get a file in, no removing entries to make something committable. If an ignored file seems to belong in the repo, ask first.

## Rules that must not drift

- The SDK never takes an amount and never accepts a `sk_` key.
- `hostedUrl` must pass `validateHostedUrl` (https, or http on loopback) before it is opened.
- The return link is a hint: `watchSession` always asks the Merchant backend.
- One `Idempotency-Key` per checkout attempt, passed through for the backend to forward.
